本地商家引入 AIGC 的重点不是一次性上线大量工具，而是选择工作量大、规则清晰、效果可复核的环节，先验证效率，再逐步扩大应用。

## 场景一：内容生产

将商品卖点、活动信息、品牌语气和禁用表达整理成结构化素材，由模型生成标题、详情页初稿、短视频脚本和多平台改写。人工负责事实核对、品牌判断和最终发布。

## 场景二：客服辅助

把常见问题、商品参数、售后规则和门店信息形成知识库，模型为客服提供回复建议和会话摘要。涉及退款、承诺、投诉和敏感信息时保留人工审批。

## 用基线判断是否有效

上线前记录任务量、平均处理时间、返工率、响应时间和人工成本；试运行后使用相同口径比较。不能只统计生成次数，还要看最终采用率、质量和业务结果。

## 从小规模走向稳定运行

先在单一门店或团队试点，建立提示词、素材、审核和异常反馈流程，再根据实际并发和时延选择 API 或专用算力。这样可以避免过早采购超出需求的资源。

<Note>
  AIGC 的降本来自流程重构与人机协作，而不是简单用模型替代全部人员。
</Note>
