企业引入 AIGC 时，最常见的问题是先采购模型或算力，再寻找可以落地的业务场景。更稳妥的方法是从业务工作量、质量要求和流程瓶颈出发，计算可验证的效率改善。

## 建立上线前基线

针对内容、客服、设计、投放或质检场景，记录月度任务量、平均处理时间、人工成本、返工率、等待时间和质量要求。没有基线，就无法判断 AIGC 带来的变化是效率提升还是任务量波动。

## 拆分人机协作环节

判断哪些步骤适合自动生成、分类、检索或总结，哪些步骤必须由人工确认。事实、价格、合同、承诺、敏感数据和品牌判断通常需要更严格的审核与权限控制。

## 反推算力需求

根据模型大小、上下文、图片分辨率、视频时长、并发、响应时间和峰谷分布估算资源。日常低频任务可采用弹性调用，稳定高频或数据敏感任务再评估专用部署。

## 比较完整成本

综合成本包括模型调用或 GPU 租赁、部署、数据整理、知识库维护、监控、人工审核和返工。还要计算试错期与流程改造成本，不能只比较 Token 或单卡费用。

## 用试点结果决定扩展

选择一个团队和一条明确流程运行试点，比较任务周期、采用率、质量、返工和业务结果。达到预设门槛后再扩大范围，并对低价值环节及时停止投入。

<Note>
  真正的降本来自流程更短、返工更少和产出更稳定，而不是单纯减少某一项算力单价。
</Note>
